# 角色资源来源

这些 PNG 原样复制自用户指定的 `/workspace/other-projects/LuLuPet/assets/pet`，未重绘、裁剪或修改原文件。主页待机动画抽取 12 帧。

- `lulu_idle_*.png`：游戏用于主页正面待机。
- `manifest.json`：各组实际帧名及 SHA-256，供资源检查使用。

资源画布为 512 × 512，脚底锚点为 (256, 464)。原资源没有背面跑步动作，早期使用的正面动作占位帧已经删除；游戏内跑酷动作改用 [runner](../runner/SOURCE.md) 中新生成的背面序列帧。原始来源项目不修改。

用户提供资源用于本项目；对外发行前由项目所有者确认其分发权。本项目未引用地铁跑酷或小黄人的美术、声音及商标资源。
